# H16 地面站

地面站支持 Android 7.1（API 25）及以上版本。安装 `android/apk/aivuda-station.apk`（或从源码构建的 `android/build/aivuda-station.apk`）后，点桌面的「Aivuda 地面站」直接打开 aivudaOS 登录页。

## 连接与登录

1. 首次使用时点「设置服务器地址」，填写飞机或测试电脑的 IP、IP 加端口，或 aivudaOS 网页地址。裸 IP 默认使用 HTTP，粘贴网页地址时取其协议、主机和端口。若使用 HTTPS 自签名证书，可在系统设置下载 CA 证书并通过 Android「设置 → 安全 → 从存储设备安装」导入后重新打开地面站。升级安装会沿用已保存的地址。
2. 输入服务器的用户名和密码，登录后进入应用控制面板。下次点桌面图标会重新显示登录页。要换服务器，点登录页标题下方的当前地址。
3. 进入左栏的「在线应用商店」可配置商店地址、选版本并安装到当前 aivudaOS 服务器。「应用菜单」按卡片启停服务端应用，点「参数」可编辑配置。Linux 应用进程在所连接的服务器运行。

构建、签名、安装和私有商店 CA 配置见 [Android 客户端 README](../android/README.md)。

## 应用面板

H16 横屏的应用控制面板每行可显示三张卡片，顶部列出运行数量和应用总数，搜索支持名称及应用 ID。「工具」收纳刷新、上传、排序和批量操作。进入商店可展开地址设置。面板返回前台会重新同步已安装应用列表。点卡片标题进入详情时才加载该应用的说明。退出地面站时释放 WebView。

## 小屏页面操作

在应用详情中，日志和版本操作分别位于独立面板。进入商店详情后，可按版本选择下载或安装。参数表列较多时，在表格内左右滑动查看默认值、范围和说明；导出配置时会呼出系统文件保存界面选择保存位置，上传安装包与导入配置支持直接从设备存储选择文件。新增参数、导入配置和 APT 源等弹窗可上下滑动，底部显示操作按钮。H16 的 APT 源编辑框以纯文本显示，兼容旧 WebView 的光标和滚动。
